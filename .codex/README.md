# .codex

Pasta local para organizar contexto reutilizavel do projeto.

## Estrutura

- `agents/`: perfis e instrucoes para agentes especializados.
- `skills/`: habilidades, fluxos e conhecimento reutilizavel.
- `memories/`: fatos persistentes, decisoes e preferencias do projeto.

## Como usar

- Crie um arquivo novo dentro da pasta apropriada quando quiser registrar algo.
- Prefira arquivos pequenos e objetivos.
- Atualize os registros quando uma decisao importante mudar.

## Sugestao de formato

- Use titulo curto no topo.
- Descreva o proposito em 1 a 3 paragrafos.
- Liste regras, preferencias ou passos em bullets.
